FOps Studio

FOps Studio is a private, self-hosted tool used by FutureOps to plan, produce and publish videos on its own YouTube channels: Routes Rewritten, Crown & Commons, MapRiddle and Wild Society.

It runs only on the owner's home network. It is not offered to the public and has no sign-up.

FOps Studio uses Google OAuth so the channel owner can let it read channel analytics and upload videos to the owner's own channels through the YouTube Data API and YouTube Analytics API.
